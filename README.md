# KlarAffär v1.0

Första publika privacy-first-versionen för https://klaraffar.se/

## Publicering
Ladda upp filerna i rotmappen i GitHub-repot som används för GitHub Pages.

## Funktioner
- Köpeavtal och kvitto mellan privatpersoner
- Produktanpassade fält
- Förhandsgranskning
- PDF skapas lokalt i webbläsaren
- Ingen registrering
- Ingen avtalsdatabas
- Ingen bilduppladdning
- SEO-landningssidor
- Integritetspolicy och användarvillkor
- sitemap.xml och robots.txt
- Canonical-adresser för klaraffar.se

## Före/vid publicering
Integritetspolicyn innehåller fortfarande en markering om att ansvarig aktör/kontaktuppgifter och faktisk hosting/logghantering ska kompletteras. Fyll i detta när den slutliga driftinformationen är bestämd.
